Restricciones

Las reglas que cuidan los datos

—

PRIMARY KEY

Cada fila tiene un identificador único: no puede haber dos materias iguales.

id_materia TEXT PRIMARY KEY

—

FOREIGN KEY

Una evaluación solo puede pertenecer a una materia que existe.

REFERENCES materia(id_materia)

—

NOT NULL

Hay datos que no pueden faltar, como el nombre de una materia.

nombre TEXT NOT NULL

—

CHECK

El valor tiene que cumplir una condición, como los créditos de una materia.

CHECK (creditos BETWEEN 1 AND 20)

—

ON DELETE

Qué pasa con los datos hijos cuando se borra al padre.

SQLite de verdad
No es una maqueta: es el motor SQLite compilado a WebAssembly, de la misma familia que usa Turso.

      
Local y privado
Nada se envía a un servidor. Los cambios que hagas viven solo en tu navegador y se borran al recargar.

      
Listo para la nube
El mismo archivo .sql se puede importar en Turso, que es SQLite en la nube.
